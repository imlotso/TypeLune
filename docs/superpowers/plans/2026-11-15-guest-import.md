# 游客资料显式导入

1. 按稳定项目 ID 收集游客收藏、私人文章、草稿、记录及已保存设置，读取旧版本机草稿和记录；草稿删除标记优先。导入的成绩仅作个人记录，草稿移除在线恢复凭据并标记个人练习。
2. 预览数量和冲突；账号已有项目、删除标记和设置默认保留，设置覆盖必须明确选择。按账号 ID 串行写入，本机步骤可重复且不创建重复项目。
3. 仅在账号云工作区已读取并同步时允许导入；写入后通过既有同步及独立读取校验目标项目。失败保留游客资料，允许重试，不将本机保存误报为云端完成。
4. 成功后由用户选择保留或清除当前浏览器游客副本；清理前复查游客资料未变化并明确提示不可恢复，不能影响账号或其他设备。游客成绩不进入公开榜单。
5. 测试去重、冲突、取消、失败重试、设置选择、游客／账号隔离及浏览器真实注册与同步。
