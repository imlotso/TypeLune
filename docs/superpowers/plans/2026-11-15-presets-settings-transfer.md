# 命名预设与练习设置导入／导出

1. 在工作区设置中增加有稳定 ID 的命名预设；明确保存语言、难度、模式、时长、严格纠错、自动暂停，以及用户选择包含的字号、行距、可见行数和指标显示。私人文章正文与输入不进入预设。
2. 支持创建、应用、更新、重命名及确认删除，最多 50 个；同步和个人数据导出包含预设，旧客户端省略字段时新服务端保留原数据。
3. 应用预设或导入设置前使用现有暂停／草稿保存流程；本机设置成功写入后才切换到下一轮，不清除未完成草稿。
4. 练习设置导出为独立版本化 JSON，仅包含明确允许的练习设置与预设；导入严格校验版本、字段、类型、范围、重复 ID 和大小，显示摘要与替换提示后确认。
5. 覆盖旧数据、隐私排除、导入失败、重复 ID、同步、预设操作和进行中切换的实际浏览器流程。
