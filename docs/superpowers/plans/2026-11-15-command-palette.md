# 快捷操作与功能面板

1. 通过可点击的功能面板入口提供搜索、暂停／继续、重新开始、设置及主要页面；动作复用既有保存、暂停和确认流程。
2. 增加可关闭的快捷键：`Alt+P` 暂停／继续、`Alt+R` 重新开始、`Alt+S` 设置、`Alt+K` 功能面板、`Ctrl+Shift+1–4` 切换主要页面。面板展示快捷键。
3. 输入法组合期间、普通表单或任何弹窗内不触发全局动作；练习输入框仅响应这些带修饰键的组合，保留 Tab、Enter、Escape 和原有纠错。
4. 快捷键偏好通过工作区、个人导出、游客导入及练习设置文件同步；旧文件默认开启，旧客户端遗漏字段时保留服务器值。
5. 验证键盘事件、搜索、禁用、草稿保护、专注模式与模拟 IME，实际浏览器检查桌面和手机。
