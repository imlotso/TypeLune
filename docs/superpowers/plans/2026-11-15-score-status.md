# 成绩提交与审核状态

1. 在服务端从本人在线练习的提交、审核及榜单选择状态计算公开状态；不把审核内部原因暴露给用户。区分未提交、待复核、已上榜、已发布但非同条件最佳、未通过、下架及不符合条件。
2. 为账号历史与当前结果提供只读、按账号或游客会话隔离的状态；状态属于服务端当前事实，旧设备本机快照不可假装是最新审核结果。未知或网络失败有明确反馈和重试。
3. 在结果和记录详情复用同一状态展示；提交响应必须校验，不能把未知响应当作已上榜。恢复入口继续依赖真实恢复资料与服务端校验。
4. 验证未提交与待复核的区分、审核批准／拒绝／下架、同条件最高成绩、过期及他人权限，并在浏览器验证结果与历史页面。
