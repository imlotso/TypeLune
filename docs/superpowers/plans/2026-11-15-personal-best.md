# 分类个人最佳和比较

1. 按语言、难度、模式、限时时长、严格纠错、文章 ID 与原文版本分组；续练偏移不同也分开。整篇不以未使用的限时配置分组。
2. 以稳定记录 ID 排除当前成绩并去重，再计算之前最高速度、最近最多 10 次同条件平均速度及准确率；首次记录不虚构提高值。
3. 成绩页按本轮条件展示个人最佳、速度提高与准确率变化。用户成绩保留个人性质，独立于服务端上榜审核。
4. 账号结果读取全部服务器历史分页并合并本机工作区；分页失败保留已读取的数据并标示范围不完整。游客仅使用本机记录。
5. 测试分组、版本变化、当前成绩排除、去重、旧记录默认值和分页失败；浏览器验证连续两轮并检查结果。
