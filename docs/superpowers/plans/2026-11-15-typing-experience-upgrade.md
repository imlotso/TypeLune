# typing 体验升级实施计划

> 按任务书的授权直接实施；每个独立交付先增加关键行为测试，再实现、验证、提交并更新需求跟踪表。此计划按系统边界拆分，完整验收以任务书逐条要求为准。

**目标：** 完成 A—F 的账号、反馈、个人数据、导航、训练及统计流程；G 保留后置。

**架构：** 继续使用 React、Fastify、SQLite 与按账号隔离的本地工作区。新增领域模块承载业务，数据库迁移保持幂等，持久化或同步字段同时更新前后端模型和校验。服务器继续判定身份、排行与审核状态。

**基线与跟踪：** `docs/qa/2026-11-15-typing-upgrade-tracker.md`。

## 全局约束

- 保留逐行输入、首个实际输入开始计时、中文输入法、暂停恢复、在线成绩恢复和文章快照。
- 保留日夜云朵小屋视觉、自定义背景、统一登录、独立管理后台以及游客与账号隔离。
- 新页面的实际操作、持久化、刷新、错误反馈和权限必须共同验收；不以模拟数据或组件状态替代。
- 不改动 `.openai/hosting.json`、`worker/index.js`、`scripts/prepare-sites-build.mjs`、`tests/sites-worker.test.mjs`。
- 不操作生产用户数据，不合并或部署；真实邮件发送及运营信息不足需单独记录。

## 实施顺序与边界

1. **账号与认证（A01–A08）**：密码输入封装、用户菜单及账号中心；用户名、邮箱、密码更改；验证码冷却；会话和公开资料。以稳定用户 ID 关联数据，敏感操作在事务中复核认证版本及唯一性，撤销所需会话。旧账号资料迁移有默认值；公开昵称与历史快照分开。
2. **反馈与基础页面（B01–B05）**：独立反馈服务、带权限检查的持久附件、用户线程与管理处理，使用版本号处理并发；站点页面内容和运营配置真实可维护。
3. **个人数据与注销（A09、C01–C05）**：安全导出、本机清理、显式游客导入；注销事务清理关联数据、成绩和会话并保护最后一位有效管理员。同步协议引入可验证的代次及重同步屏障，保留旧设备待导出内容，禁止旧协议不安全写入，再实现删除标记回收和容量统计。
4. **路由与历史（D01–D06）**：稳定路径、历史合并筛选删除、公开成绩撤回和审核状态；复用草稿恢复，导航前保存练习；私人文章编辑保护未保存内容。
5. **训练（E01–E08）**：纯函数比较同条件成绩；复用专项训练、预设和带版本设置的同步；快捷操作避开组合输入、表单和弹窗；配速和显示设置不改变计分或排行。
6. **统计与分享（F01–F04）**：按账号时区聚合可用历史，标明覆盖范围；新增有界、按有效时间采样并可持久化恢复的过程序列；分享卡只包含用户选择的公开摘要。
7. **回归与交付**：执行项目脚本、两会话同步、权限和迁移测试，检查桌面／手机及日夜界面并保存截图；整理 API、数据协议、备份回退、运营缺口和剩余问题。

## 重点回归

- 异步密码验证期间账号状态发生变化或两个请求并发。
- 邮件失败、验证码过期或已消费时旧邮箱保持有效。
- 设备离线跨越删除标记回收时，不自动复活旧数据且保留未同步内容的恢复机会。
- 旧客户端、新字段、缺失采样和不完整历史不能被误当作完整且已验证的数据。
- 中文组合输入、跨行退格、切换预设或路由不会触发错误快捷操作或丢失进度。
