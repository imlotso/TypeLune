# 目标配速

1. 新增默认关闭的配速设置，可选择自定义速度、当前条件的上次成绩或个人最佳；中文使用字／分，英文使用 WPM。
2. 以本轮正确字符数和有效用时计算与目标的时间差；英文目标按每 5 个正确字符为 1 WPM 换算。暂停不推进，配速只展示、不改评分或上榜资格。
3. 本轮首次输入时固定可用目标，并将目标随草稿和记录保存、恢复和同步；目标尚未读取或不存在时继续本机练习且不编造目标。
4. 配速配置随设置、预设及设置文件保存；旧文件和旧客户端写入不抹掉已有字段。全量历史不可用时明确标示已读取范围。
5. 测试中英文换算、相同条件来源、暂停／恢复、旧数据与双设备同步，并实际走查移动端。
