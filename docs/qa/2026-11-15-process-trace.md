# 单次练习过程采样

- 新练习以有效用时为横轴，基础间隔 5 秒，暂停和结束时保留实际观测点；暂停期间不推进时间。仅对已提交的输入计算进度与正确数，未提交的输入法组合文本不计入。每个点保存相对本轮起点的进度、当前正确数和累计错误输入次数，不保存额外的原文或击键事件。
- 每轮最多 720 个点、序列化不超过 64 KiB；超限时保留首尾并合并相邻采样，将采样基准加倍并标记已合并。计时器推迟超过当前基准的 1.5 倍时标记缺失，不插值。旧草稿续练从恢复位置开始采样并标记此前缺失；旧记录显示“暂无过程数据”。
- 速度图按每段净正确字符增长除以该段有效分钟数；净增长为负时按零计算，英文再除以 5。柱状图显示每段新增错误输入次数，并非最终未改正错误数。稳定性采用 `100 × max(0, 1 − 用时加权分段速度标准差 / 用时加权平均速度)`，四舍五入为整数。至少 3 段、15 秒、平均速度大于零且没有缺失才显示数值；该指标不宣称等同 Monkeytype。采样仅供个人分析，不参与服务端计分、审核或上榜判断。
- `PracticeRecord` 和 `SavedPractice` 增加可选 `processTrace`，草稿增加 `processErrorEvents`。现有 IndexedDB/降级存储、云工作区、游客导入、个人数据导出及历史合并传递它们；前后端限制结构、时间顺序、点数和大小。旧客户端写回记录时保留已有过程数据；旧客户端更改草稿进度但不带新字段时保留已有点并标记缺失，不能假定旧设备期间的数据完整。
- 不新增数据库表或列。部署前按既有流程备份 SQLite、WAL 一致状态及持久化卷；旧服务不识别新增 JSON 字段，回退后继续写入可能丢失这些数据，应先保留完整备份并恢复相应版本。没有操作生产数据。
- 自动化验证覆盖有界合并、顺序与格式校验、暂停和恢复、旧数据、模拟中文组合输入及旧客户端同步；浏览器验证通过真实两设备草稿同步与结果／历史显示。真实系统输入法及最终全站回归尚待验证。
