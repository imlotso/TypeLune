# 本机账号缓存清理检查

- 清理前除工作区同步状态外，还检查属于当前账号、保存在独立旧版存储中的草稿和历史记录。未能与工作区副本核对的项目单独提示；不可解析或不完整的数据显示无法确认。其他账号和游客记录不计入当前账号的项目数，也不会被本次清理。
- 出现风险时可以立即重试工作区同步、导出完整个人数据、导出本机资料或确认放弃。本机导出独立保留可读取的旧草稿／记录副本，即使它与云端删除标记冲突；导出仍不包含恢复密钥、验证码、密码或会话材料。无法解析的旧数据会在导出缺失项中列明，不能声称已完整备份。独立旧版副本不会因点击工作区同步就自动变成云端资料。
- 确认后再次读取本机副本；退出请求前保护当前账号并检查最新工作区是否出现新的未同步项目。退出请求等待期间再次比较本机副本和工作区；若发生变化，保留本机缓存并提示重新登录后同步或导出。比较信息只在本机使用，不发送到服务器。
- 自动化测试覆盖账号隔离、损坏资料、确认后变化和实际本机导出；浏览器测试覆盖已同步记录／草稿、未同步提示、重新登录、游客和背景隔离，以及模拟旧页面在退出请求期间分别写入 localStorage 与 IndexedDB。已查看[桌面](screenshots/local-cleanup-legacy-desktop.png)与[手机](screenshots/local-cleanup-legacy-mobile.png)界面。
- 新客户端遵守清理保护标记；极旧页面可能不遵守标记。最终比较与不同存储的清除不是跨浏览器存储的原子事务，极旧页面在比较之后或清理完成后继续写入仍不能完全阻止。清理和注销界面已提示先关闭此设备的旧版页面；该边界及最终全站回归保留为待验收事项。永久离线的其他设备不会被即时清理。
