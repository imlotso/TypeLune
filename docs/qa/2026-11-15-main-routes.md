# 主要页面地址阶段记录

练习、文章库、排行榜、记录、草稿、错字本、统计、反馈、个人数据、帮助、关于、隐私和条款分别使用 `/`、`/library`、`/rankings`、`/records`、`/drafts`、`/mistakes`、`/stats`、`/feedback`、`/account/data`、`/help`、`/about`、`/privacy`、`/terms`。路径会被前端实际解析为对应视图；未知路径显示“页面未找到”。游客访问个人数据页时要求登录，成功登录后保留原地址。

站内切页在原有暂停和保存逻辑成功后更新地址。浏览器前进／后退同样先保存进行中的练习；保存失败会返回当前地址和输入。弹窗打开时浏览器历史操作先触发弹窗的 Escape 处理，私人文章编辑器因此能显示未保存修改确认。前端在自身创建的历史条目中保存序号，以在拦截前进／后退时恢复原条目而不破坏后续历史。已有管理员统一登录、独立后台和显式前台预览保持角色分流。静态托管仍使用已有应用入口回退，不能以该回退单独认定路由已实现。

一次浏览器测试发现仅使用 `replaceState` 恢复被拦截的返回会覆盖上一条历史；已改为按历史序号反向恢复，并补充返回／前进后再次导航和草稿保存失败测试。另发现排行榜接口返回缺失字段时组件会崩溃，现显示错误并允许重试。涉及测试中隔离地址状态的清理已调整。

公共文章链接、账号中心、记录详情和反馈详情的独立路径及跨账号权限深链尚未接入；从应用以外创建、没有本应用历史序号的同源条目仍使用保守的地址恢复。D01 继续标为待完善。
