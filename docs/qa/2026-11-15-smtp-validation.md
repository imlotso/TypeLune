# 邮件配置与验证码验证

- 开发入口不再支持把验证码打印到终端的 `MAIL_DEV_MODE=console`。未配置 SMTP 时，验证码请求返回“邮件服务尚未配置”，不会声称邮件已发送；测试专用服务使用独立内存邮箱，不进入生产入口。
- `tests/dev-mail-logging.test.ts` 以临时数据库启动实际开发入口，验证旧环境变量不再输出验证码且请求返回 503。`tests/smtp-wire.test.ts` 启动仅监听本机的临时 SMTP 测试接收端，使用真实 TCP／SMTP 会话验证后台连接测试不会发信、验证码邮件能被接收端接受，以及连接关闭后测试准确失败。测试消息仅保存在进程内，不输出验证码。
- 该本机 SMTP 测试没有验证外部服务商、TLS 证书、账号凭据或真实收件箱送达。实际 SMTP 连接测试和真实邮件送达仍需运营方提供配置与测试邮箱，必须分别记录；本次没有使用生产邮件或用户数据。
