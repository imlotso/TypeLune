# TypeLune interface locale verification

Branch: `dot/typelune-ui-i18n`, based on main `bfc139a0208ea1b85e87aee6570d82131050e77e`.
No production changes, deployment or real mail sends.

## Implemented
- Browser preferred locale selects Chinese for zh variants, English otherwise. Explicit choice persists locally, syncs across same-origin tabs and remains usable when storage is blocked.
- Interface language is separate from exercise language and article content. Language changes do not remount practice or reset draft input.
- A compact Translate / EN / 中文 toggle appears beside appearance/account actions. Administrator shell toggle is integrated with the separate unsaved-change guard work.
- Source-level bilingual UI in practice, account/login, library, rankings, history/drafts/mistakes, statistics/calendar, feedback, settings/backgrounds, admin tools, help/privacy/terms and result cards. User-generated content and internal identifiers are preserved.
- Light and dark background editors are directly accessible from Appearance, without first changing the active theme.
