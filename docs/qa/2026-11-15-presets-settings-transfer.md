# 练习预设与设置文件

预设保存在工作区设置的可选 `presets` 数组中，最多 50 项，每项有稳定 ID 和名称。内容包含语言、难度、限时／整篇、分钟数、严格纠错和自动暂停；选择包含阅读设置时，还包含字号、行距、可见行数及实时指标开关。预设不保存私人文章正文、输入、草稿或认证材料。可创建、应用、更新、重命名和确认删除；旧账号没有数组时按空列表处理。

应用预设或导入设置使用现有暂停和草稿流程，成功保存设置后切换下一轮。若旧式草稿存储不可用，会核实工作区中的本机副本；本机标记只存在工作区本地元数据，不上传。恢复此类个人草稿时另存新副本并保留原副本，保留输入、有效用时和误输；已有在线恢复仍由原有服务端校验处理。切换期间使用可用的本地草稿租约；旧客户端及完全离线设备不能获得即时通知。

练习设置文件使用 `typing-practice-settings` 版本 1，大小上限 256 KiB。仅包含语言、难度、规则、阅读／指标设置及预设，不包含完整个人资料、背景、错字状态、文章正文、输入、密码、会话或恢复材料。导入前校验格式、版本、字段、类型、范围及预设 ID 唯一性，并显示将替换的内容；确认后替换练习设置和预设，保留其他账号数据。完整个人数据 JSON 导出与此文件相互独立。

新服务端接受可选预设字段，旧设置可继续读取；旧客户端提交不含预设的设置时保留服务端已有预设。回退到不识别预设的旧服务前应停止写入并备份，不能直接继续同步以免丢弃字段。预设操作的交互思路参考 [Monkeytype 预设](https://github.com/monkeytypegame/monkeytype/blob/3aa6c2e448d3d13084daac678070ca9734b77ba1/frontend/src/ts/components/pages/settings/custom-setting/Presets.tsx)和[设置导入导出](https://github.com/monkeytypegame/monkeytype/blob/3aa6c2e448d3d13084daac678070ca9734b77ba1/frontend/src/ts/components/pages/settings/custom-setting/ImportExport.tsx)。
