# 个人数据导出说明

账号菜单中的“个人数据”提供版本为 1 的 `typing-personal-data` JSON 和独立的练习记录 CSV。导出按账号 ID 读取本机工作区、旧版本机草稿／最近 50 条旧版历史、云工作区、服务端完整历史及站内反馈，并按记录和工作区项目的稳定 ID 合并。JSON 包含账号基本资料、设置、收藏、私人文章、草稿、记录、背景和本人反馈及其可读取附件；不包含密码、会话令牌、验证码、草稿恢复密钥或练习认领材料。反馈正文及截图属于用户自行提供的内容，导出会原样包含其中的用户内容。

服务端历史新增 `GET /api/history?limit=100&cursor=...` 游标分页；未传分页参数时保留原有最多 100 条的响应，避免破坏旧客户端。游标按完成时间和记录 ID 排序，不包含认证材料。CSV 中可能被电子表格解释为公式的文本会加前缀保护。

导出只读取，不执行同步写入或删除。无法读取的云端、反馈、附件或历史页面会记录在 JSON 的 `missing` 中并显示在界面；导出期间数据仍可能被其他设备修改，其他设备尚未同步到云端的内容不在当前设备的导出中。JSON 中的草稿不包含恢复凭据，因此不能仅凭导出文件恢复已认证的排行榜资格。浏览器需要支持文件下载；大图和大量历史会增加处理时间和文件体积。
