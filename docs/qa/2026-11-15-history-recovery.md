# 历史成绩恢复阶段记录

- 历史详情在存在可用恢复资料时提供“恢复成绩”，复用草稿箱已有的在线恢复和提交逻辑；账号、游客会话、恢复凭据、认领版本、时长、原文及服务端审核仍由原有流程验证。个人文章、无正确输入、整篇未完成、用时不足、缺少资料、租约被其他页面持有，以及已提交或审核结束的成绩会显示无法恢复的原因。
- 本机完成记录与本机恢复草稿按稳定记录／在线练习 ID 关联，点击时再次读取并检查当前草稿和租约。账号另一设备可使用同步的恢复草稿，但必须与该账号历史记录的原文快照、输入、有效用时、退格、模式、时长和计分摘要一致；不使用历史速度授予资格。同步资料变化或本机租约被占用时保留当前页面并提示重新查看。
- 联调发现恢复请求失败会改变恢复标记，使内容和认领版本相同的完成草稿被误判为冲突。现在只有文章快照、输入、时间、认领版本及进度版本一致时才忽略请求标记差异；不同进度或认领版本仍保留冲突保护。草稿箱原有的个人结果查看不受排行资格判断限制。
- 浏览器验证了离线完成后从历史恢复并提交待复核、另一账号设备恢复同步资料、个人练习不可上榜、以及点击前另一标签页占用租约；原有恢复和成绩状态流程也纳入回归。已查看[手机夜间](screenshots/history-recovery-mobile-dark.png)与[桌面日间](screenshots/history-recovery-desktop-light.png)入口。
- 恢复资格和期限最终由服务端决定；恢复资料缺失必要原文、输入或用时、本机和云端资料不一致、原资料未同步或其他设备永久离线时不能凭结果数值重建。真实系统中文输入法和最终整体回归仍未完成，D05 保持待完善。
