# 旧版历史兼容阶段记录

- 旧版 `cloudtyping.history.v1` 不再只读取前 50 项；保存新成绩时保留其他账号、游客以及超出 50 项的旧条目，不因显示上限截断原数组。浏览器存储空间不足时不会用截断数组覆盖旧数据；工作区保存仍按原有独立路径执行并报告失败。
- 可读旧记录保留原有成绩；缺少记录 ID 时沿用游客导入已有的稳定标识算法。文章快照缺少后来增加的语言、难度或公开／私人标记时，按该记录的语言、难度作为个人快照展示，不把缺失信息推定为已验证的公共文章；无法读取正文的记录仍显示成绩摘要。任何不完整条目会在记录／统计／错字视图和个人导出中提示，不会被保存新成绩时静默丢弃。
- Playwright 在真实浏览器中写入 65 条旧记录、一条缺字段且无 ID 的旧记录及一条损坏条目，完成新练习后验证原数据保留、逐批显示、损坏提示以及无 ID 记录删除。个人导出测试确认可读记录仍可导出且缺失部分被列出。
- 云工作区中极早期没有 `recordId` 且项目 ID 与本机计算标识不同的特殊记录仍需单独迁移核对；本阶段没有把 D03 标为完整验收。原本就未保存在设备或已被旧版本截断的历史无法凭空恢复。

## 跨标签页结算回归

一次完整单元回归出现两个“练习成绩”弹窗。通过延迟服务器 `/finish` 响应稳定复现：在线启动完成后，第一标签页尚未结算，但已完成草稿的 `pendingStart` 已为 false，第二标签页因此把仍由第一标签页持有租约的草稿恢复为离线成绩。恢复旧草稿时现在同时检查已完成草稿的现有租约，另一标签页结算期间不重复恢复。原先模拟待启动场景和新增延迟结算场景各重复 15 次通过；实际双标签页浏览器测试及原有在线恢复流程需随阶段回归一起记录。
