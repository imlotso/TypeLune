# 记录详情地址阶段记录

记录详情使用 `/records/:id`；列表详情按钮更新地址，直接访问、刷新、返回和前进会打开对应详情。旧版无 ID 的本机记录使用与游客导入一致的稳定标识。记录仍从当前账号的服务端历史和工作区，或当前游客的本机空间读取；地址本身不授予权限，也不会查询其他账号记录。

记录尚在读取时显示加载状态；历史请求失败、工作区尚未完整同步或旧版数据不完整时显示“记录尚未完整读取”并提供重试，不把这种情况误报为记录不存在。数据读取完整且无对应记录时显示“记录未找到”。重练和续练继续使用已有快照及草稿逻辑。

浏览器验证了游客详情刷新和前进／后退、另一游客设备及另一账号的隔离、历史请求失败后重试，以及旧版无 ID 记录的打开与删除；实际检查了[手机日间](screenshots/record-route-mobile-light.png)和[桌面夜间](screenshots/record-route-desktop-dark.png)界面。账号中心和反馈详情地址仍待接入，D01 保持待完善。
