# 成绩状态与审核说明阶段记录

- 服务端按当前账号或游客 Cookie 返回本人在线成绩状态：尚未提交、已提交待复核、已上榜、已发布但榜单展示同条件最高成绩、审核未通过、下架或不符合排行条件。未提交状态可标明已过提交期限；按现有流程恢复时仍须通过恢复凭据、认领和成绩审核。
- 榜单按账号／游客、语言、难度、模式、严格纠错及限时时长选择个人最高成绩；“已上榜”表示该成绩是上述全部时段榜单当前选中的成绩。“已发布”不保证该次成绩是榜单展示项。删除或下架较高成绩后，状态会根据剩余成绩重新计算。
- `GET /api/tests/:id/score-status` 和账号历史响应返回服务端计算的状态，按拥有者隔离且不返回内部风控原因。状态属于实时服务端事实，不作为工作区持久字段回写；合并本机和云记录时不会把缓存的旧状态冒充当前审核结果。结果与记录详情统一显示状态；接口不可用或响应无效时显示错误并提供重试。提交响应不符合协议时不显示成功，并重新查询服务端，响应丢失后若实际已提交可显示真实状态。
- 审核拒绝和下架可填写独立的“用户可见说明”；内部审核原因仍只在管理审计中。历史及状态接口只返回用户可见说明，不返回内部审核原因或风控标记。
- 数据库迁移为 `challenges` 增加可空的用户可见说明字段和用于按拥有者查询榜单的索引；旧记录默认无说明并使用简短的处理说明，迁移可重复执行。上线前应使用 SQLite 备份 API 或既有备份流程保存数据库、WAL 一致状态及持久化卷，在备份副本验证升级与回退。前后端应同步升级；旧服务没有状态接口，新前端会提示暂不可用。旧版本回退不会理解新状态及公开说明，不能把它作为已经完整回退的方案；本次未操作生产数据。
- 单元／接口测试覆盖未提交与待复核、批准／拒绝／下架、较低成绩、到期、无效输入、跨账号隔离、旧数据库迁移及内部原因不外泄。浏览器走通提交、后台拒绝、用户结果与历史刷新，以及提交回包丢失后的服务端核对。已查看[手机夜间](screenshots/score-status-mobile-dark.png)和[桌面日间](screenshots/score-status-desktop-light.png)界面。
