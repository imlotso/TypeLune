## 验证

- `npm run typecheck`、`npm test`：通过，104 个测试文件、541 项测试。
- `npm run build`、`npm run test:sites`：通过，Sites 4 项；构建保留客户端包大于 500 kB 的提示。
- `npm run test:e2e -- --output /tmp/typing-full-e2e-final-1c1fa`：113 项通过，涵盖页面路由、账号、反馈、权限、两个设备同步、恢复、统计、分享和桌面／手机视口。普通浏览器套件使用测试邮箱和模拟组合事件。
- `docker build -t typing-upgrade-ci:local .`、`DAZI_TEST_IMAGE=typing-upgrade-ci:local npm run test:docker`：通过容器替换、持久卷与 SQLite 备份恢复，包括反馈附件、统计设置和旧记录标记。
- `scripts/verify-system-ime.sh`：在独立 Xvfb、Fcitx5 拼音和 Chrome X11 中通过可信组合输入、首次计时、过程采样、快捷键保护、跨行退格及暂停／刷新／继续。详细环境与截图见[记录](2026-11-15-system-ime.md)；Windows、macOS 和手机系统输入法未实测。
- 上一版前端 `809de62` 连接当前隔离测试服务，验证旧版同步被拒、页面提示更新及本机记录保留，见[复现方法](2026-11-15-legacy-workspace-records.md)。
- 本机预览使用独立临时数据库，监听 `http://127.0.0.1:4195`；没有连接真实 SMTP，验证码请求会明确失败。未使用生产用户数据。

## 未完成及后置

- 外部 SMTP 的实际连接和真实邮件送达，以及正式运营主体、联系邮箱和政策生效日期待运营配置。
- 不支持 Navigation API 的浏览器，对应用外未标记的同源历史条目仍使用保守回退。
- 极旧版本记录的标识冲突可单独安全删除；如果新的内容摘要标识本身又被不同记录占用，仍会阻止误删。无法唯一匹配的其他旧数据在满额工作区可能需要先释放容量；上一版客户端已实测，其他历史版本交替使用仍需验收。
- 不遵守清理保护标记的极旧标签页，可能在跨存储最终比较后继续写入；现有检查会保留在退出请求期间观察到的变化，但不能提供跨存储原子保证。
- G01—G04（快速／定量练习、慢词、完整回放、音效与更多光标）按任务书后置，未实施。
