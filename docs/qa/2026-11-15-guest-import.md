# 游客资料导入说明

登录或注册后，当前浏览器有游客资料时会出现导入入口；账号的个人数据页面也可手动打开。默认不自动合并。预览列出私人文章、收藏、草稿、记录、设置和背景；相同 ID 的账号项目及删除标记默认保留，已有账号设置只有明确勾选后才覆盖。预览后账号设置若发生变化，不会用旧预览覆盖新值。

导入使用原有工作区和同步协议。游客草稿复制为账号下的个人练习并去除在线恢复凭据；游客记录标为个人记录，不会变为服务端认证成绩或自动上榜。旧记录没有 ID 时按内容生成稳定标识，冲突不会静默覆盖。旧版历史读取完整数组；旧版草稿或记录无法解析时停止导入并保留原始数据。

账号必须先读取并完成同步。导入先保存本机，再通过既有同步和服务端重新读取逐项核对；网络失败、配额不足或冲突时，提示尚未同步并保留游客副本，可重试。核对成功后用户可继续保留副本，或确认清除当前浏览器的游客副本；清除前再次检查游客数据未变化。清理设置短时互斥租约，避免新版标签页同时写入；旧版本页面不能识别该租约，界面提示用户先保存并关闭其他游客页面。清理不会删除云端账号资料或其他账号资料。

此功能尚需与记录删除、后续设置字段和完整导出／恢复流程一起最终回归。运营环境没有在本次操作中使用。
